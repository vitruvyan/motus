# Motus 0.20.0 — AI System Registry v1

Motus 0.20.0 adds the jurisdiction-neutral AI System Registry v1 boundary
accepted in ADR-041. Immutable registration claims, separate append-only
lifecycle event claims, and bounded registry snapshots remain distinct evidence
types. Read-only verification reports exact identities, supplied lineage,
manifest bindings, correction conflicts, and subset-scoped lifecycle projection
without deciding legal AI-system status, deployment, approval, official
registration, compliance, global current state, or inventory completeness.

## Verification and cost

Three independent Jenkins relative characterisations (`#25`, `#26`, `#27`)
against v0.19.0 measured canonical medians of **-3.6% / -2.3% / -2.4%**.
Their job ranges were **-5.3% to -3.5% / -3.3% to +5.3% / -6.7% to
-0.2%**. All pass the unchanged +10% per-release budget; every measured effect
is narrower than the worst paired spread.

The cumulative arm against v0.6.1 remains an explicit FAIL at
**+106.9% / +131.3% / +24.6%**, with ranges **+101.4% to +113.0% /
+122.0% to +131.9% / +21.2% to +28.2%**. ADR-018 leaves the anchor and
budget unchanged and permits release only with the fresh real-workload evidence
below.

Five live Orbis requests on `localhost:8001/run` produced contract-valid Motus
traces with integrity chains. Motus costs were **6.7 / 2.6 / 2.9 / 4.7 /
4.0 ms** against request durations of **5.887 / 9.928 / 7.050 / 8.696 /
10.272 s**. The conservative share, the worst cost over the fastest request,
is **0.114%**, below ADR-018's pre-registered 1% ceiling. The service still
omitted the health metadata expected by the probe, so the runs are honestly
classified `degraded`; this is Motus cost evidence, not Orbis health evidence.

Jenkins absolute-characterisation build `#28` used the same candidate SHA
`cb47451de41f60b1d7d8774f567774006ecbe4bb`. Its committed Python 3.10.12
profile identifies runtime `vitruvyan-motus/0.20.0` and passes the SLO baseline
gate, recording 257.900 microseconds per node and 18.625 milliseconds for the
100-node no-op subject. No figure is inherited from v0.19.0.

The release workflow appends the SHA-256 of the exact wheel and sdist below.
Those bytes are stored as an immutable workflow artifact and as draft GitHub
Release assets. Publishing that draft would trigger PyPI and is not authorised.
