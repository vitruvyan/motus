# Motus 0.15.0 — Risk & Control Registry / ControlApplication

Motus 0.15.0 adds the jurisdiction-agnostic Risk & Control Registry and the
`ControlApplication` evidence document accepted in ADR-036. Risk and control
declarations remain separate from evidence that a control was applied during a
specific execution. The CLI and Python API validate both documents and verify
their bindings to the execution trace.

## Verification and cost

- Jenkins branch and PR-head CI passed on the reviewed release commit.
- Three interleaved relative characterisations against v0.14.0 measured
  **+5.3% / -1.0% / +0.9%** at the canonical medians, all inside the unchanged
  +10% per-release budget.
- Cumulative medians against v0.6.1 are **+109.0% / +129.0% / +23.0%**. The
  cumulative gate remains a disclosed FAIL under ADR-018; no budget was widened
  or waived.
- Five live Orbis traces validated under schema 3.2.0. The most conservative
  observed Motus executor share was **0.175%**, below the pre-registered 1%
  ceiling. The Orbis response omitted the expected health metadata, so those
  runs establish executor overhead and trace validity, not service health.

The release workflow appends the SHA-256 of the exact wheel and sdist below.
Those bytes are stored both as the immutable workflow artifact and as draft
GitHub Release assets; publication refuses if the two copies differ.
