# Motus 0.22.0 — Verification and Query API/CLI v1

Motus 0.22.0 adds the transport-neutral, read-only Verification and Query
API/CLI v1 boundary accepted in ADR-043. Callers explicitly type every supplied
artifact and request a closed inspection, verification, or projection over that
exact bounded collection. Motus composes its existing structural, binding,
lineage, package, dossier, and profile authorities without discovering external
evidence, guessing artifact kinds, selecting global current state, or issuing a
compliance or legal verdict.

The distinct `motus-evidence` CLI exposes deterministic JSON and terminal-safe
human output. Missing companions, duplicate identities, conflicting revisions,
forks, incomplete lineage, exhausted work budgets, and incomplete supplied-set
scope remain visible rather than being silently resolved.

## Verification and cost

Release characterization evidence will be recorded here from three independent
Jenkins relative runs against v0.21.0, the unchanged v0.6.1 cumulative anchor,
one absolute Python 3.10.12 run, and—if the cumulative arm remains red—the fresh
ADR-018 real-workload qualification. No figures are inherited from v0.21.0.

The release workflow will append the SHA-256 of the exact wheel and sdist. Those
bytes will be stored as an immutable workflow artifact and as draft GitHub
Release assets. Publishing that draft would trigger PyPI and is not authorised.
