# Motus 0.17.0 — Regulatory Evidence Profile v1

Motus 0.17.0 adds the jurisdiction-neutral Regulatory Evidence Profile v1
accepted in ADR-038. A profile maps opaque external requirement references to
existing Motus evidence kinds, and the deterministic assessment surface reports
whether that evidence is present and verifiable. It does not interpret law,
decide compliance, or change the semantics or wire formats of the existing
execution, system, risk/control, control-application, or human-oversight
evidence.
